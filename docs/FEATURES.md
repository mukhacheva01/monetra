# Функциональность Monetra

## MVP

### Dashboard

- сводка расходов за текущий месяц
- сравнение доходов и расходов
- карточки использования бюджета
- блок последних транзакций
- кнопка быстрого добавления

### Transactions

- добавление расхода
- добавление дохода
- редактирование и удаление записей
- поиск по заметкам
- фильтрация по дате и категории

### Categories

- базовые категории по умолчанию
- пользовательские категории
- выбор цвета и иконки

### Budgets

- месячные лимиты по категориям
- отслеживание прогресса
- предупреждения о перерасходе

### Analytics

- расходы по категориям
- недельная динамика
- сравнение по месяцам
- самые затратные категории

### Settings

- переключение темной и светлой темы
- выбор валюты
- экспорт в CSV
- заглушка под настройки синхронизации

## Что добавить после MVP

- регулярные расходы
- цели накоплений
- отслеживание подписок
- несколько счетов или кошельков
- теги помимо категорий
- split-транзакции
- прикрепление чеков
- биометрическая защита
- общий семейный бюджет
- облачный backup и восстановление
- push-напоминания о лимитах бюджета

## Продвинутые идеи на будущее

- AI-сводки по тратам
- обнаружение необычных расходов
- прогноз бюджета
- умные подсказки для категорий
- импорт банковских операций
