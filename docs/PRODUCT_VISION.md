# Видение продукта Monetra

## Коротко о продукте

Monetra — это приложение для личных финансов с темной темой, которое делает учет расходов быстрым, понятным и ненавязчивым.

## Какую проблему решает

Многие финансовые приложения перегружены, медленные или слишком похожи на бухгалтерские системы. Пользователю нужен инструмент, который помогает:

- быстро записывать расходы
- без усилий понимать свои финансовые привычки
- держать бюджет под контролем
- быть уверенным, что данные доступны офлайн

## Целевая аудитория

- студенты и молодые специалисты
- пользователи, которым нужен личный бюджет без сложных банковских сценариев
- люди, которым нравится аккуратный интерфейс и понятные ежедневные действия
- пользователи, которым важны офлайн-режим и приватность

## Принципы продукта

- `Local-first`: приложение остается полезным без интернета
- `Скорость важнее формальностей`: расход должен добавляться за секунды
- `Польза важнее шума`: каждый график отвечает на конкретный вопрос
- `Приватность по умолчанию`: данные хранятся локально в первую очередь
- `Чистый UX`: простая навигация, сильная визуальная иерархия, минимум лишних шагов

## Основные пользовательские сценарии

### 1. Быстрое добавление расхода

Пользователь открывает приложение, нажимает добавить, выбирает категорию, вводит сумму и сохраняет запись за несколько секунд.

### 2. Контроль месячного бюджета

Пользователь задает лимиты по категориям, видит прогресс и получает предупреждения при приближении к пределу.

### 3. Понимание своих трат

Пользователь открывает аналитику и видит:

- расходы за неделю и месяц
- самые затратные категории
- динамику трат по времени
- использование бюджета и сигналы о перерасходе

### 4. Надежность локальных данных

Пользователь может пользоваться приложением офлайн и при желании позже подключить синхронизацию для резервного хранения и использования на нескольких устройствах.

## Цель MVP

Собрать отполированное мобильное приложение с local-first подходом, в котором уже есть:

- учет расходов и доходов
- категории
- бюджеты
- дашборд
- аналитика
- темная тема
- экспорт данных и готовая архитектура для синхронизации

## Характер продукта

Monetra должна ощущаться как:

- современная
- точная
- спокойная
- аккуратная
- персональная, а не корпоративная
