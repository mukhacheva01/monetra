# Monetra

Monetra — мобильное приложение для учета личных финансов с упором на быстрый ввод расходов, чистый темный интерфейс, локальное хранение и готовую основу для синхронизации.

## Основная идея

Monetra помогает быстро фиксировать ежедневные траты, распределять их по категориям, следить за бюджетами и понимать свои финансовые привычки с помощью наглядной аналитики.

Приложение должно ощущаться как:
- быстрое
- простое в ежедневном использовании
- спокойное визуально
- полезное даже без интернета

## Главная ценность

- Добавление расходов за несколько нажатий
- Понимание, куда уходят деньги за неделю и месяц
- Контроль лимитов по категориям до перерасхода
- Надежное локальное хранение данных с возможностью синхронизации в будущем

## Рекомендуемый стек

- `Flutter` для единой кодовой базы под iOS и Android
- `Riverpod` для предсказуемого управления состоянием
- `Drift + SQLite` для локальной базы данных
- `fl_chart` для графиков и аналитики
- `Supabase` на следующем этапе для авторизации, облачной синхронизации и резервного хранения

## Основные модули

- `dashboard` — обзор, сводка, быстрые действия
- `transactions` — расходы, доходы, фильтры, поиск
- `categories` — управление категориями и иконками
- `budgets` — месячные лимиты и прогресс
- `analytics` — графики, сравнения и разбор трат
- `settings` — тема, валюта, экспорт, параметры синхронизации
